📈 Time Series Analysis & Retail Sales Forecasting
Complete end-to-end Python portfolio project for retail sales analytics and forecasting.

Features
EDA and data validation
Trend and rolling averages
Seasonality
MoM and YoY growth
Anomaly detection
Time-series decomposition
ADF, ACF and PACF
Holt-Winters
SARIMA
Random Forest
MAE, RMSE, MAPE
Automatic best-model selection
12-month forecast
Business insights
Streamlit dashboard
Jupyter notebook
Tests and GitHub Actions
Structure
data/                 dataset
dashboard/            Streamlit dashboard
docs/                 documentation
notebooks/            Jupyter notebook
outputs/              generated results
tests/                automated tests
main.py               complete analysis pipeline
requirements.txt      dependencies
Run
pip install -r requirements.txt
python main.py
streamlit run dashboard/app.py
