# Project Report

## Objective
Analyze monthly retail sales and forecast the next 12 months.

## Methods
EDA, rolling averages, seasonality, YoY/MoM growth, IQR anomaly detection, decomposition, ADF, ACF/PACF, Holt-Winters, SARIMA and Random Forest.

## Evaluation
Models are compared using MAE, RMSE and MAPE. The lowest-RMSE model is selected for the final forecast.

## Note
The included dataset is synthetic and intended for portfolio/educational use.
